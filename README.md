## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/chetandhapola2004/portfolio.git
```

Navigate to the project

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```
